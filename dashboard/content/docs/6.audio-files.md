# Audio Files on FreePBX

Assistants can play pre-recorded audio instead of TTS. Here's how to manage audio files on your PBX.

## Upload Location

Upload files to your FreePBX server:

```bash
/var/lib/asterisk/sounds/custom/
```

## Referencing in Code

Use the format `sound:custom/filename` — **no file extension**. Asterisk auto-selects the best format matching the channel codec.

```javascript
channel.play({ media: "sound:custom/welcome_2" })
// → Plays /var/lib/asterisk/sounds/custom/welcome_2.{sln16,ulaw,alaw,...}
```

## Recommended Formats

| Strategy | Format | Details |
|----------|--------|---------|
| **Best single format** | `sln16` | Signed linear 16-bit 16kHz. Highest quality, Asterisk transcodes on the fly. |
| **Best performance** | Multiple | Provide `sln16` + `ulaw` + `alaw` + `g722` — avoids runtime transcoding CPU cost. |

## Converting with Sox

Convert any audio file to sln16:

```bash
sox source.wav -r 16000 -t raw -e signed -b 16 file.sln16
```

For multiple formats:

```bash
sox source.wav -r 8000 -t raw -e mu-law -b 8 file.ulaw
sox source.wav -r 8000 -t raw -e a-law -b 8 file.alaw
sox source.wav -r 16000 -t raw -e signed -b 16 file.sln16
sox source.wav -r 16000 -c 1 file.g722
```

::callout{type="tip"}
**Start with just `sln16`.** It's the highest quality format and Asterisk will transcode it automatically. Only add other formats if you notice CPU load from transcoding on high-traffic systems.
::

## Managing via Dashboard

The **Assets** page lets you browse and upload files to the PBX server via SFTP. Files uploaded to the `custom/` sounds directory will be available to all assistants immediately.
