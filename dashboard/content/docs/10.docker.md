# Docker Deployment

Run the full AriLink stack with Docker Compose. Four services start automatically: Dashboard, Asterisk, Parakeet (STT), and Kokoro (TTS).

## Quick Start

```bash
docker compose up -d
open http://localhost:3011
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| **AriLink** | 3011 | Dashboard + API + Socket.IO |
| **Asterisk** | 5060 (SIP), 8088 (ARI) | PBX with ARI enabled |
| **Parakeet** | 5000 | AI speech-to-text |
| **Kokoro** | 5001 | AI text-to-speech |
| **Rust RTP** | 9900 | Echo cancellation + VAD (optional) |

## Container Management

When running in Docker, the dashboard can manage containers directly — no SSH needed.

### What You Can Do

- **View status**: Each service card on the Home page shows container state, health status, and uptime
- **Restart containers**: Click the power icon on any service card, or use the "Restart Container" button on the Config page
- **Auto-reconnect**: After a container restart, AriLink automatically reconnects the affected service (transcription, TTS, or ARI)

### How It Works

The AriLink container has the Docker socket mounted (read-only). It communicates with sibling containers through a hardcoded allowlist:

| Slug | Container Name |
|------|---------------|
| `parakeet` | `arilink-parakeet` |
| `kokoro` | `arilink-kokoro` |
| `asterisk` | `arilink-asterisk` |
| `rust-rtp` | `arilink-rust-rtp` |

### REST API

```bash
# Container statuses
GET /api/docker/status

# Restart a container
POST /api/docker/restart
Body: { "service": "kokoro" }
```

### Local Development

When running without Docker (e.g. `npm run dev`), container management is hidden automatically. Only software-level reconnect buttons are shown.

## GPU Acceleration

For faster STT and TTS with an NVIDIA GPU:

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d
```

Requires NVIDIA GPU + [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).

## Rust RTP Server (Optional)

For echo cancellation and neural VAD:

```bash
docker compose --profile rust-rtp up -d
```

Set `USE_RUST_RTP=true` in `.env` to route audio through it.

## Environment Variables

Key Docker-specific variables:

| Variable | Description | Default |
|----------|-------------|---------|
| `DOCKER_MANAGEMENT` | Enable container management | `true` |
| `PORT` / `NITRO_PORT` | Dashboard port inside container | `3011` |
| `USE_RUST_RTP` | Route audio through Rust RTP | `false` |

See [Environment](/docs/environment) for the full list.
