# Configuring Assistants

Each assistant is a folder in `assistants/` with a `config.json` and optional TypeScript logic or flow definition. You can customize behavior from the **Assistants** page in the dashboard.

## Assistant Types

### Flow (Visual Builder)
Scripted IVR phone tree built with a drag-and-drop canvas. No code, no AI, zero cost per call. Set `brain: "flow"` in config.json.
- **Mode:** incoming
- **Use case:** Phone menus, call routing, data collection, API integrations
- **Tabs:** Flow | Config (Code and Prompt tabs are hidden)
- See [Flow Builder](/docs/flow-builder) for full documentation

### LLM Chat (AI-Powered)
Conversational AI assistant using streaming LLM responses with tool calling. Set `brain: "llm-chat"` in config.json.
- **Mode:** incoming
- **Use case:** Customer service, appointment booking, FAQ handling
- **Tabs:** Flow (Mermaid diagram) | Config | Prompt | Code

## Built-in Assistants

### IVR Transfer
Plays a welcome message, listens for the caller's request, then transfers to the appropriate extension or ring group.
- **Mode:** incoming
- **Use case:** General reception, front-desk routing

### Direct Dial
Voice-powered dial-by-name. Caller says a name, system matches it against a contact list and dials the matching extension.
- **Mode:** incoming
- **Use case:** Office directory, hands-free dialing

### Auto Dialer Call
Handles outbound campaign calls. Plays a script, listens for DTMF input (e.g., press 1 to transfer to a human).
- **Mode:** outbound
- **Use case:** Marketing campaigns, surveys, appointment reminders

## Key Config Fields

| Field | Description |
|-------|-------------|
| `name` | Display name shown in the dashboard |
| `mode` | `incoming` or `outbound` — determines where the assistant appears |
| `behavior.maxRetries` | How many times to retry before giving up |
| `behavior.timeoutSeconds` | Max wait for caller input before timeout action |
| `behavior.silenceThresholdSeconds` | How long silence counts as "caller stopped talking" |
| `prompts.welcome` | Initial greeting text (TTS or audio file reference) |
| `prompts.transferring` | Message played when transferring the call |

## Creating a New Assistant

1. Go to **Assistants** page → click **New**
2. Enter a slug (folder name) and display name
3. This creates `assistants/<slug>/config.json` with defaults
4. Customize the config via the dashboard editor
5. For custom logic, add `<Name>Assistant.ts` in the folder

::callout{type="info"}
Assistants are discovered automatically on startup. The system scans `assistants/` for any folder containing a `*Assistant.ts` file (skipping `base/`).
::
