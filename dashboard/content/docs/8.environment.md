# Environment Variables

Configure these in your `.env` file at the project root. **Never commit this file** — it contains credentials.

## Required

| Variable | Description |
|----------|-------------|
| `ASTERISK_LOGIN` | ARI username configured in Asterisk |
| `ASTERISK_PASSWORD` | ARI password |
| `PBX_IP` | IP address of your FreePBX server |
| `LISTENER_SERVER` | IP/hostname of this server (where Rust RTP listens) |
| `TRANSCRIPTION_SERVICES` | Comma-separated transcription endpoints (see below) |

## Transcription Services

The `TRANSCRIPTION_SERVICES` variable accepts a comma-separated list. The first entry is primary, the rest are automatic fallbacks.

```bash
# Parakeet only
TRANSCRIPTION_SERVICES=ws://localhost:5000

# Parakeet with Google fallback
TRANSCRIPTION_SERVICES=ws://localhost:5000,google

# Two Parakeet instances (load balancing)
TRANSCRIPTION_SERVICES=ws://localhost:5000,ws://localhost:5001
```

::callout{type="info"}
The keyword `google` refers to Google Cloud Speech. It requires `GOOGLE_APPLICATION_CREDENTIALS` to be set to your service account JSON path.
::

## TTS (Text-to-Speech)

AriLink supports two TTS providers. Switch between them on the **Config** page or via `.env`.

| Variable | Description | Default |
|----------|-------------|---------|
| `TTS_PROVIDER` | `kokoro` (local) or `elevenlabs` (cloud) | `kokoro` |
| `TTS_SERVICE` | Kokoro WebSocket URL | `ws://localhost:5001` |
| `TTS_VOICE` | Kokoro voice name | `af_heart` |
| `TTS_SPEED` | Kokoro speech rate | `1.0` |
| `TTS_LANG` | Kokoro language code (see below) | `a` |
| `ELEVENLABS_API_KEY` | ElevenLabs API key (required for cloud TTS) | — |
| `ELEVENLABS_VOICE_ID` | ElevenLabs voice ID | — |
| `ELEVENLABS_MODEL` | ElevenLabs model ID | `eleven_flash_v2_5` |

### Kokoro Language Codes

| Code | Language | Code | Language |
|------|----------|------|----------|
| `a` | English (US) | `i` | Italian |
| `b` | English (UK) | `j` | Japanese |
| `e` | Spanish | `p` | Portuguese (BR) |
| `f` | French | `z` | Chinese |
| `h` | Hindi | | |

::callout{type="info"}
Kokoro runs locally — no API key needed. ElevenLabs supports 29+ languages including Polish. Configure the provider on the **Config** page where you can test it and browse available models/voices.
::

## Optional — Docker Management

| Variable | Description | Default |
|----------|-------------|---------|
| `DOCKER_MANAGEMENT` | Enable/disable container management from dashboard | `true` (when socket is mounted) |

## Optional — 3CX Integration

| Variable | Description |
|----------|-------------|
| `RING_GROUP_3CX` | 3CX ring group for transfers |
| `TRUNK_3CX` | SIP trunk name to 3CX |
| `3CX_SERVER_IP` | IP address of your 3CX server |

## Example `.env`

```bash
# ARI Credentials
ASTERISK_LOGIN=arilink
ASTERISK_PASSWORD=your-secure-password

# Network
PBX_IP=192.168.1.100
LISTENER_SERVER=192.168.1.50

# Transcription
TRANSCRIPTION_SERVICES=ws://localhost:5000,google
GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json

# TTS
TTS_PROVIDER=kokoro
TTS_SERVICE=ws://localhost:5001
TTS_VOICE=af_heart
TTS_SPEED=1.0

# Optional: ElevenLabs (cloud TTS)
# TTS_PROVIDER=elevenlabs
# ELEVENLABS_API_KEY=sk-...
# ELEVENLABS_VOICE_ID=21m00Tcm4TlvDq8ikWAM

# Optional: 3CX
# RING_GROUP_3CX=100
# TRUNK_3CX=3cx-trunk
# 3CX_SERVER_IP=192.168.1.200
```

::callout{type="warning"}
Changes saved on the **Config** page are written to `.env` and auto-applied. Services that need reconnection (TTS, ARI, Transcription) reconnect automatically after saving.
::
