📊 Live Dashboard (Observable JS)

This chart is rendered live in the browser using Observable JS. No backend required!

Code 
viewof callVolume = Inputs.range([0, 100], {label: "Simulated Call Volume", step: 1})
viewof region = Inputs.radio(["US-East", "EU-West", "Asia-Pacific"], {label: "Region", value: "US-East"})
Code 
data = {
  const points = [];
  for (let i = 0; i < 24; i++) {
    points.push({
      hour: i,
      calls: Math.max(0, Math.floor(callVolume * (Math.sin((i - 14) / 4) + 1.5) + (Math.random() * 10 - 5)))
    });
  }
  return points;
}

// Render the chart
Plot.plot({
  title: `Projected Call Traffic (${region})`,
  subtitle: "24-hour forecast based on historical models",
  y: { grid: true, label: "Active Calls" },
  x: { label: "Hour of Day" },
  marks: [
    Plot.areaY(data, {x: "hour", y: "calls", fill: "steelblue", fillOpacity: 0.3}),
    Plot.lineY(data, {x: "hour", y: "calls", stroke: "steelblue", strokeWidth: 2}),
    Plot.ruleY([0])
  ]
})

🏗️ System Architecture

Using tabsets, we can organize complex information cleanly.

  • 🗺️ Flow Overview
  • ⏱️ Call Sequence
  • 📝 Description

The AriLink system handles calls in real-time. - RTP Stream: Audio is intercepted and sent to Google. - WebSocket: Transcription updates are pushed to the frontend. - Latency: Typically < 500ms for partial results.

🧩 Component Breakdown

📡 Server-Side

The AriControllerServer manages the connection to Asterisk.

  • Protocol: WebSocket (ARI)
  • Role: State Managment
  • Scale: Horizontal

☁️ Cloud Services

Computation heavy tasks are offloaded.

  • Speech-to-Text: Google Cloud
  • Storage: S3 / Local
  • Logging: Winston / CloudWatch
